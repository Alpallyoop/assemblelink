# AssembleLink Roadmap

> **Status (2026-10-20).** Shipped in the 0.1.0 pre-release: the v0.1 and v0.2 items (inventory, profile, plans, approved install flow, progress, retry, receipts and an install history page) and the core of v0.3 (blueprint export/import, compare, manual checklist). Update availability is shown per item.
> **Not built yet:** the v0.4 usage-intelligence items (install date, last used, most used, largest software). **Release blockers:** a trusted code-signing route and the clean-machine scenarios; see CHANGELOG.
